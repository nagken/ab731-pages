# AB-731 Glossary

| Term | Meaning |
|---|---|
| **Adoption metric** | Activation, prompts/user - vanity metric without productivity backing |
| **AI Council** | Cross-functional governance body for AI |
| **Azure AI Foundry** | Developer platform for AI apps (model catalog, prompt flow, eval) |
| **Azure OpenAI** | Enterprise GPT / embedding / DALL-E in your Azure tenant |
| **Build vs Buy** | Choose between custom (Copilot Studio / Azure AI) and Microsoft Copilot products |
| **Champions network** | Distributed evangelists / mentors (~1 per 50 users) |
| **Change management** | Process to drive adoption: champions, training, surveys |
| **Cloud Adoption Framework (CAF)** | Microsoft's standard methodology for cloud transformation |
| **Content Credentials** | C2PA standard provenance metadata in AI-generated images |
| **Content Safety** | Azure service to filter unsafe AI input/output |
| **Copilot for Finance** | Excel + ERP financial helper |
| **Copilot for Sales** | Dynamics 365 Sales + M365 helper for sellers |
| **Copilot for Service** | Dynamics 365 Customer Service helper for agents |
| **Copilot Studio** | Low-code platform to build custom Copilot agents |
| **Customer experience (CX) value bucket** | Better, faster, personalized customer interactions |
| **Defection / deflection rate** | % of support tickets resolved by AI without human |
| **DLP** | Data Loss Prevention (Microsoft Purview) |
| **EU AI Act** | EU regulation classifying AI risk + obligations |
| **GitHub Copilot** | Code-completion AI for developers |
| **Impact Assessment** | RAI process for evaluating new AI use cases |
| **KPI** | Key Performance Indicator |
| **M365 Copilot** | Per-user-licensed Copilot in Word/Excel/PPT/Outlook/Teams |
| **M365 Copilot Chat** | Web-grounded chat (free with M365) |
| **Microsoft Copyright Commitment** | Microsoft defends customers against IP claims for Copilot output |
| **Microsoft Graph** | API for tenant data (mail, files, chats) |
| **New revenue value bucket** | AI-enabled products + monetization |
| **Optimization Assessment** | Free Microsoft tool to detect oversharing risks |
| **Oversharing** | SharePoint files accessible too broadly |
| **PAYG** | Pay-as-you-go (Azure consumption pricing) |
| **Pilot** | 4-8 week limited-user proof of value |
| **Productivity value bucket** | Doing existing work faster |
| **Prompt library** | Curated prompts for users |
| **PTU** | Provisioned Throughput Unit (Azure OpenAI) |
| **Purview** | Microsoft compliance + information protection platform |
| **RAI Standard v2** | Microsoft Responsible AI Standard (public framework) |
| **ROI** | Return on Investment |
| **Scale phase** | Department-by-department expansion after pilot |
| **Sensitivity label** | Microsoft Purview classification (Confidential, etc.) |
| **Vision phase** | Define one-line AI vision + KPIs |
