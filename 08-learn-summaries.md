# AB-731 Learn Summaries

> Microsoft Learn summaries grouped by domain.

## Domain 1 - Business Value of Generative AI

**Identifying business value.** Generative AI delivers value in three buckets: productivity (do existing work faster - drafting, summarizing, search), customer experience (better, faster, personalized - chatbots, recommendations), and new revenue (AI-enabled products and services). ROI is calculated from time saved, hourly cost, and license cost. Adoption metrics alone are vanity - measure productivity and business outcome (revenue, NPS, deflection rate). Use a risk-vs-value matrix to prioritize: pilot high-value low-risk first; reserve high-risk strategic use cases (customer-facing chatbots, automated decisioning) for after governance is mature. Different stakeholders (CEO, CFO, CIO, CISO, Legal) need different talking points.

## Domain 2 - Microsoft AI Apps and Services

**The Microsoft AI portfolio.** End users have Microsoft Copilot (free, web), Microsoft 365 Copilot (work, per-user license), Microsoft 365 Copilot Chat (free with M365 sub), and role-specific Copilots for Sales / Service / Finance. Makers use Copilot Studio (low-code, agents, connectors, knowledge sources). Developers use Azure AI Foundry (model catalog, prompt flow, evaluations) and Azure OpenAI for production AI apps; GitHub Copilot for code generation. Build vs buy: buy Microsoft 365 Copilot for generic productivity, build with Copilot Studio for niche workflows, build with Azure AI Foundry for differentiating customer-facing AI.

## Domain 3 - Implementation and Adoption Strategy

**Enterprise rollout.** Five-phase adoption journey: Vision (clear KPIs) -> Readiness (data + identity hygiene; Microsoft 365 Copilot Optimization Assessment to find oversharing) -> Pilot (4-8 weeks, 50-300 users, high-value low-risk use case) -> Scale (department by department) -> Optimize (continuous improvement). Responsible AI governance combines policy (Responsible AI Standard v2), process (Impact Assessment per use case), people (RAI council), technology (Azure AI Content Safety, audit). Change management is the #1 success factor: champions network (1 per 50 users), continuous training, prompt library, monthly surveys. Data hygiene before flipping on Copilot: SharePoint access reviews, Microsoft Purview sensitivity labels and DLP. Pricing varies: M365 Copilot per-user/month, Copilot Studio per-message capacity, Azure OpenAI consumption-based.
