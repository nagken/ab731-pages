# AB-731 Exam Cheatsheet

> Print-friendly. The 60-second reset before exam time.

## The 3 domains

| Domain | Weight | Key skills |
|---|---|---|
| Business Value of GenAI | 33% | Use-case archetypes, ROI, productivity / CX / revenue |
| Microsoft AI Apps and Services | 33% | M365 Copilot, Copilot Studio, Azure AI Foundry, GitHub Copilot |

## Microsoft AI portfolio (memorize)

| Tool | Audience | Build/Buy |
|---|---|---|
| Microsoft Copilot (free) | End user (web) | Buy (free) |
| Microsoft 365 Copilot | M365 user | Buy |
| Microsoft 365 Copilot Chat | M365 user (web grounding) | Buy (free with M365 sub) |
| Copilot for Sales / Service / Finance | Role-specific | Buy |
| Copilot Studio | Maker | Build (low code) |
| Azure AI Foundry / Azure OpenAI | Developer | Build (high code) |
| GitHub Copilot | Developer | Buy (per user) |

## ROI formula

```
ROI = (time_saved_per_user * hourly_cost - license_cost) * users
```

## Use-case prioritization

- **Pilot first**: high value + low risk (productivity / drafting / summarization).
- **Strategic but governed**: high value + high risk (customer-facing, automated decisions).
- **Skip / monitor**: low value.

## Adoption journey (5 stages)

Vision -> Readiness -> Pilot -> Scale -> Optimize.

## Responsible AI components

- Policy (Microsoft Responsible AI Standard v2).
- Process (Impact Assessment per use case).
- People (RAI council).
- Technology (Content Safety, audit, monitoring).

## Change management essentials

- Champions network (1 per 50 users).
- Prompt library + office hours.
- Continuous training (not one-shot).
- Monthly surveys.

## Data readiness

- SharePoint access review.
- Microsoft Purview sensitivity labels + DLP.
- Microsoft 365 Copilot Optimization Assessment (free).
