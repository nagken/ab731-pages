## Readiness checklist

- [ ] You can name the **3 domains** + their weights.
- [ ] You can list the **3 value buckets** (productivity, CX, new revenue).
- [ ] You can compute basic **ROI** for an AI use case.
- [ ] You can map every Microsoft AI product to its audience: Copilot (free) / M365 Copilot / Copilot for Sales-Service-Finance / Copilot Studio / Azure AI Foundry / GitHub Copilot.
- [ ] You can pick **build vs buy** for a use case.
- [ ] You can name the **5 phases** of adoption.
- [ ] You can describe Microsoft's **Responsible AI Standard v2** and the **Impact Assessment** process.
- [ ] You can describe the **Microsoft 365 Copilot Optimization Assessment** and why it matters.
- [ ] You can explain the **Microsoft Copyright Commitment**.
- [ ] You can describe a **champions network** and its ratio.
- [ ] You can explain why **adoption metrics alone are vanity**.
- [ ] You can explain that **M365 Copilot tenant data does NOT train foundation models**.
